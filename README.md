# ChildPlay

叮咚配對樂園 (Ding Dong Match) — 一個給四歲小朋友玩的雙語（中/英）互動小遊戲。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可（不需要安裝或建置任何東西）。

- **🎯 配對模式**：畫面會用中英雙語念出「找找看,小狗在哪裡?」，小朋友點對圖卡就會有慶祝動畫、彩帶和稱讚語音；點錯只有溫柔的提示音，沒有任何負面懲罰，可以一直開心地玩下去。
- **🔍 探索模式**：點任何圖卡都會念出雙語名稱（例如「小狗 / Dog」），適合純粹探索、認識新單字。

內容涵蓋農場動物、海洋生物、交通工具三種混合主題，共 23 種圖卡，每回合隨機抽 6 張。

## 技術說明

單一 `index.html` 檔案，純 HTML/CSS/JavaScript，使用 Emoji 作為圖像（不需外部圖檔），並透過瀏覽器內建的 `SpeechSynthesis`（雙語語音）與 `Web Audio API`（音效）提供互動回饋。可在任何現代瀏覽器（含平板觸控）直接開啟使用。
